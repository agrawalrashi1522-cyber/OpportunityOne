Opportunity One 🌍

An AI-powered opportunity discovery assistant for government schemes, scholarships, and internships.

💡 Problem Statement

Students, farmers, and job seekers often struggle to find relevant opportunities because information is spread across multiple websites and portals.

🚀 Our Solution

Opportunity One helps users discover relevant opportunities through a guided conversational experience based on their nationality, country of residence, occupation, and education level.

✨ Features

- 🌐 Nationality and country-based onboarding
- 🎓 Scholarship and education-loan discovery
- 🌾 Indian government scheme suggestions
- 💼 Internship search guidance
- 📄 Document preparation guidance
- 🔗 Links to official opportunity portals
- 🗣️ Conversational interaction through Amazon Alexa

🛠️ Technology Stack

- Python
- Amazon Alexa Skills Kit
- Alexa Developer Console
- Amazon Lambda-compatible handler

📚 Opportunity Categories

- Government schemes
- Scholarships
- International study opportunities
- Internships
- Document guidance

⚙️ Setup

1. Clone or download this repository.
2. Install the Amazon Alexa Skills Kit Python SDK.
3. Configure the required intents and slots in the Alexa Developer Console.
4. Deploy the Python handler using your Alexa skill's supported backend.
5. Test the skill using the Alexa Simulator.

Install the SDK dependency:

pip install ask-sdk-core

⚠️ Important Disclaimer

The current prototype uses a curated starter catalogue. Eligibility, deadlines, vacancies, and required documents can change. Always verify details through the linked official portals. Live vacancy verification is not currently guaranteed.
